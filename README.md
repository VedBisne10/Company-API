# Company REST API

A simple REST API built using Node.js and Express.js for managing company data.

## Features

- Get all companies
- Get a company by ID
- Add a new company
- Update a company
- Delete a company
- Basic error handling
- JSON request and response data

## Technologies Used

- Node.js
- Express.js
- JavaScript
- Postman for API testing

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/VedBisne10/Company-API.git
```
2. Go to the project directory:
```bash
cd CompaniesAPI
```
4. Open the terminal and run:
```bash
npm install
```
5. In the terminal, run:
```bash
node server.js
```
