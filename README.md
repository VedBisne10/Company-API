# Company REST API

A simple REST API built using Node.js and Express.js for managing company data.

## Features

- Get all companies
- Get a company by ID
- Add a new company
- Update a company
- Delete a company
- Basic error handling
- JSON request and response data

## Technologies Used

- Node.js
- Express.js
- JavaScript
- Postman for API testing
